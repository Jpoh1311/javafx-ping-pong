# JavaFX Ping Pong

A desktop Ping Pong game developed in Java using JavaFX as part of my BSc (Hons) in Computer Systems at Munster Technological University.

The project was developed to apply object-oriented programming principles, GUI development, testing, persistence and database integration in a complete application.

## Technologies

- Java 17
- JavaFX
- Maven
- JUnit
- SQL / Database persistence
- IntelliJ IDEA

## Features

- Two-player Ping Pong gameplay
- Paddle and ball movement
- Collision detection
- Progressive ball-speed changes
- Score tracking
- Pause functionality
- Pre-game countdown
- Saving and loading game state
- Database-backed game records
- JUnit testing of collision logic

## Software Design

The application was structured using object-oriented design principles and separates responsibilities across areas such as:

- Game controllers
- Input handling
- Game logic
- Model classes
- Persistence / database access
- Testing

The project also includes use of design patterns and structured data-access classes for storing and retrieving game information.

## Testing

JUnit tests were used to verify important game logic, including collision behaviour.

This project gave me practical experience with:

- Building a complete Java application
- JavaFX GUI and event handling
- Object-oriented software design
- Maven project management
- Unit testing with JUnit
- File persistence and serialization
- Database integration
- Debugging and iterative development
